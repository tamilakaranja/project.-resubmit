# My Home Finder

## About the Project

My Home Finder is a responsive property website that helps users discover houses, apartments, and other properties available for rent or purchase across Kenya.

## Features

- Home section with an introduction and property search
- Featured property listings
- Rent and Buy sections
- About Us section with an introductory video
- Contact Us section with contact information
- Navigation links that take users directly to different sections
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- Git and GitHub

## Project Structure

my-home-finder/
├── index.html
├── style.css
├── images/
└── videos/

## How to Run

1. Open the project in Visual Studio Code.
2. Open `index.html`.
3. Use Live Server to run the website.
4. Use the navigation bar to explore the different sections.

## Purpose

This project was created to practice HTML and CSS by building a real-world property website. It demonstrates webpage structure, navigation using IDs, images, video, styling, and responsive design.
